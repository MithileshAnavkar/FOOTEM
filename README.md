# ⚽ FOOTEM — Football Analytics

FOOTEM is a FIFA-inspired football analytics platform designed to make player statistics and performance analysis more interactive and engaging. Built using Python and Streamlit, it combines FIFA-style player cards with detailed football data visualization.

## 🚀 Features

- **FIFA-Style Player Cards:** Explore players through visually appealing cards displaying their overall rating, position, club, nationality, and key attributes.
- **Player Search:** Find players quickly using an interactive search feature.
- **Detailed Player Statistics:** Analyze attributes such as Pace, Shooting, Passing, Dribbling, Defending, and Physicality.
- **Player Comparison:** Compare two players using their overall ratings and individual performance attributes.
- **Interactive Visualizations:** Explore player performance through charts and statistical comparisons.
- **FIFA 23 Dataset:** Discover player information using FIFA 23 football data.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Application logic |
| Streamlit | Interactive web interface |
| Pandas | Data processing and analysis |
| Plotly | Interactive charts and visualizations |
| Requests | Fetching player images and external resources |

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/FOOTEM.git
```

### 2. Navigate to the project directory

```bash
cd FOOTEM
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 📊 Dataset

FOOTEM uses FIFA 23 player data containing information such as:

- Player names and ratings
- Clubs and nationalities
- Playing positions
- Technical and physical attributes

## 🎯 Project Objective

The objective of FOOTEM is to provide a simple and interactive platform for exploring football player statistics, comparing player performance, and presenting football data through a modern, FIFA-inspired interface.
